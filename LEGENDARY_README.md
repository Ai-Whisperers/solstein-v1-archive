### ❌ Issue 1: Nomenclature Schizophrenia
**Problem:** Marketing says "Phoenix/Salt/Lead" but code says "Rocket/Dinosaur/Neutral"
**Fix:** Phase 1 - Unified terminology everywhere
**Impact:** Investor credibility, client clarity

### ❌ Issue 2: Fake Frontend Versions
**Problem:** package.json claims Next.js 16.1.6 and React 19.2.3 (don't exist)
**Fix:** Phase 1 - Update to realistic versions (Next.js 15, React 18)
**Impact:** Dashboard won't build, security vulnerabilities

### ❌ Issue 3: Bloated Repository
**Problem:** 46 directories, 4.8MB graveyard (SolStein_original), 3 dead UI templates
**Fix:** Phase 1 - Delete 4.8MB+ of abandoned code
**Impact:** Clarity, focus, repo health

### ❌ Issue 4: Abandoned Features
**Problem:** Celery workflows undefined, CLI 0% coverage, 9 failing tests
**Fix:** Phase 2 - Remove Celery, delete CLI, fix tests
**Impact:** Core functionality complete, zero broken tests

### ❌ Issue 5: "Explainability Theater"
**Problem:** Magic numbers (GITHUB=0.95, NEWS=0.75) with no documentation
**Fix:** Phase 3 - Document methodology with evidence, validate weights
**Impact:** Real explainability, client trust

### ❌ Issue 6: Database Confusion
**Problem:** JSON files still used, PostgreSQL half-integrated, unclear truth
**Fix:** Phase 2 - Full PostgreSQL migration, zero JSON reads
**Impact:** Scalability, ACID compliance, enterprise readiness

### ❌ Issue 7: C# Migration Limbo
**Problem:** 1200-line .NET 8 plan abandoned in archive (decision never made)
**Fix:** Phase 1 - Decide Python-first forever, delete C# plan
**Impact:** Clear direction, focused effort, no wasted resources

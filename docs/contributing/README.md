# Contributing to API Discovery

This guide explains how to suggest and contribute new data sources.

## Fast Path

1. Submit a suggestion using the `API Source Suggestion` issue template.
2. Include evidence of value for Solstein use cases.
3. If approved, open an adapter contribution PR following the adapter guide.

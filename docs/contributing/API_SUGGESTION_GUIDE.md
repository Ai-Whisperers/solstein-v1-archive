# API Suggestion Guide

## Required Information

- API name and provider
- Official documentation URL
- Category
- Solstein use case

## Optional but Useful

- Pricing tier and trial availability
- Authentication type
- Rate limits
- Geographic or industry coverage
- Known data quality constraints

## Review Criteria

- Relevance to competitive intelligence workflows
- Feasibility of adapter integration
- Expected signal quality
- Operational risk and cost

# Security Policy

## Supported Versions

Currently, the following versions of the project are being supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| v1.0.x  | :white_check_mark: |
| < v1.0  | :x:                |

## Reporting a Vulnerability

We take the security of Solstein very seriously. If you discover a vulnerability, we would like to know about it so we can take steps to address it as quickly as possible.

Please do not report security vulnerabilities through public GitHub issues.

Instead, please report them via email to **contact@ai-whisperers.com**. You should receive a response within 48 hours. If the issue is confirmed, we will release a patch as soon as possible, depending on complexity, but with high priority.

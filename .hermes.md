# Solstein — Hermes Agent Context

## What Is This Project
Solstein is an AI-powered competitive intelligence platform for Private Equity.
It replaces McKinsey/BCG 90-day engagements with 3-day AI-driven market maps.
Python 3.10+, FastAPI, SQLAlchemy 2.0, PostgreSQL, Celery+Redis, LangGraph.

## Architecture
```
Data Sources → Adapters → Research Pipeline → Scoring Engine → Export
    (11)        (enrichment)   (pipeline.py)    (analytics/)    (exporters/)
                               CANONICAL         3 dimensions    Excel/CSV/PDF/MD
```

1. `research/pipeline.py` — CANONICAL (sequential, production)

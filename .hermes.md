## Autoresearch Protocol (Karpathy Pattern)
Every change follows: MEASURE → CHANGE → TEST → MEASURE → KEEP/DISCARD
1. Baseline metrics BEFORE any work
2. One small change at a time
3. Test immediately after each change
4. Revert if tests break — try different approach
5. Commit ONLY with green tests
6. Include metrics delta in every commit message

# FD-022: Phase 3 Styling Pass

## Objective

Apply consistent professional styling across all new Phase 3 sheets. Same quality standard as Phase 1 styling (FD-005) -- the new sheets must look like they belong in the same workbook, not bolted on.

## Requirements

1. Apply workbook color palette to all Phase 3 sheets (FD-012 through FD-021)
2. Consistent header styling: same font, size, color, borders as Phase 1 sheets
3. Consistent number formatting: EUR with thousands separator, percentages with 1 decimal
4. Consistent conditional formatting patterns: Rocket=green, Dinosaur=red, Eneve=yellow highlight
5. Frozen header rows on all sheets
6. Column widths auto-fitted with minimum widths for readability
7. Print-ready: landscape orientation, fit to page, confidential footer
8. Tab colors: Phase 3 sheets get a distinct but complementary tab color to Phase 1
9. Sheet ordering: Phase 3 sheets placed logically after Phase 1, with AI Maturity and Portfolio Risk near the front

## Dependencies

- All Phase 3 feature tickets (FD-012 through FD-021) must be complete

## Complexity Assessment

**Track**: Complex Implementation (touches all Phase 3 sheets)
- Effort: 2-3h

## Acceptance Criteria

- [ ] All Phase 3 sheets match Phase 1 visual quality
- [ ] Color palette consistent throughout
- [ ] Headers, fonts, number formats consistent
- [ ] Print-ready on all sheets
- [ ] Confidential footer on all sheets
- [ ] Tab colors applied
- [ ] Sheet ordering logical

# .antigravity/ — Agent Prompt Library

This directory contains prompt templates, exemplars, rules, and scripts
used by AI coding agents (Antigravity framework) to work on Solstein.

**This is NOT project documentation.** These are agent operating instructions.

## Structure
- `prompts/` — Prompt templates organized by domain (191 files)
- `exemplars/` — Example outputs for quality calibration (40 files)
- `rules/` — Behavioral rules and constraints (15 files)
- `templars/` — Code/ticket templates (18 files)
- `commands/` — Agent slash commands (10 files)
- `scripts/` — Quality check scripts (2 files)

## Do Not Edit Unless
You understand the agent workflow and are intentionally changing
how agents generate code, tickets, or documentation.

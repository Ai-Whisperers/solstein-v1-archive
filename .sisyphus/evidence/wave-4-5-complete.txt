================================================================================

Documented in: SETUP.md (lines 130-145)

Required Secrets:
✅ DATABASE_URL_TEST - Supabase test database URL

Setup Instructions:
1. Go to GitHub repository: Settings → Secrets and variables → Actions
2. Click "New repository secret"
3. Name: DATABASE_URL_TEST
4. Value: postgresql://postgres:[password]@db.[project].supabase.co:5432/postgres?sslmode=require
5. Click "Add secret"

Security Notes:
- Secrets are encrypted and not visible in logs
- Secrets are not available to forks in PRs
- Never commit credentials to git
